# File Editor Skill

This skill provides tools for editing files on the filesystem. Use these targets to modify existing files or create new ones.

## Available Targets

- **insert_line**: Insert text at a specific line number in a file
  - Parameters: `file_path` (str), `line_number` (int), `text` (str)
  
- **replace_text**: Replace specific text within a file
  - Parameters: `file_path` (str), `old_text` (str), `new_text` (str)
  
- **append_text**: Add text to the end of a file
  - Parameters: `file_path` (str), `text` (str)
  
- **delete_lines**: Remove a range of lines from a file
  - Parameters: `file_path` (str), `start_line` (int), `end_line` (int)
  
- **create_file**: Create a new file with initial content
  - Parameters: `file_path` (str), `content` (str)

## Important Notes

- Line numbers are 1-indexed (first line is 1)
- For `replace_text`, the match is exact and replaces all occurrences
- Always ensure the file exists before editing it (unless creating a new file)
- After editing, consider reading the file to verify changes
